2. Problem Statement

The main problem is fine recognition of space targets from polarimetric ISAR images. Since satellite ISAR images contain structure-sensitive scattering information, the objective is not only to classify the target but also to identify and localize important components such as body parts, antennas, solar arrays, fittings and optical lenses.

The working problem statement is:

To develop and evaluate robust learning-based methods for polarimetric ISAR space target fine recognition and component-level oriented object detection by using magnitude, phase and full-polarimetric fusion information from HH, HV, VH and VV channels.

7. Complex CNN Classification

A Complex CNN was implemented to process complex-valued polarimetric data. The idea was to preserve both real and imaginary information rather than discarding phase by using magnitude-only images.

Core principle:

For a complex input x = a + jb and complex convolution weights W = Wr + jWi, the complex convolution is:

Real output = Wr(a) - Wi(b)
Imaginary output = Wr(b) + Wi(a)

The implemented architecture included:

1. Complex convolution layers
2. Complex batch normalization
3. Complex activation
4. Residual blocks
5. Feature extraction from higher layers
6. Final classification head

After guide feedback, unnecessary object-detection heads were removed from the classification notebook because the classification task only required class prediction and feature extraction from a fully connected layer.

8. Magnitude and Phase Feature Extraction

For each full-polarimetric image, features were extracted from:

HH, HV, VH and VV

Magnitude:
Magnitude = sqrt(real^2 + imaginary^2)

Phase:
Phase = atan2(imaginary, real)

The feature vector was formed using:

[mag_HH, mag_HV, mag_VH, mag_VV, phase_HH, phase_HV, phase_VH, phase_VV]

In one feature study, each channel was resized/downsampled to 64 x 64 before flattening. Therefore, each image was represented using 32768 feature values.

Feature matrices created:

Train: 1314 x 32768
Validation: 162 x 32768
Test: 162 x 32768 in that specific notebook run

11. ResNet18 Magnitude-Only Baseline

A ResNet18 magnitude-only baseline was implemented to compare normal CNN behavior against complex/polarimetric feature approaches.

Setup:

1. Input: 4-channel magnitude only
2. No phase used
3. No complex-valued arithmetic
4. First ResNet18 convolution modified for 4-channel input
5. Magnitude mean and standard deviation computed from training data only
6. Same statistics applied to validation and test
7. Training augmentation applied only to the training set

Observed result from one run:

Test accuracy: 0.4136
Test macro-F1: 0.3805

Interpretation:

The ResNet18 model showed weak generalization in that run. This suggests that a normal CNN on magnitude-only data is not automatically sufficient. However, the result should be treated as an initial baseline and should be repeated using best-validation checkpoint selection and improved regularization.

18. YOLO-OBB Detection Pipeline

The DOTA-style labels were converted into Ultralytics YOLO-OBB format.

Original DOTA-style format:

x1 y1 x2 y2 x3 y3 x4 y4 class difficult

YOLO-OBB format:

class x1 y1 x2 y2 x3 y3 x4 y4

The coordinates were normalized to the 0 to 1 range.

19. Detection Inputs Compared

Three input representations were compared:

1. Single-VV baseline

Input:
VV amplitude image.

Reason:
VV is a standard single-polarization baseline and performed strongly.

2. Fixed Pauli fusion

Input generated from full-polarimetric channels:

R = |HH - VV|
G = |HV + VH|
B = |HH + VV|

Reason:
Pauli decomposition is physically meaningful and uses polarimetric information.

3. Learned fusion

Input:
HH, HV, VH and VV complex data represented as real and imaginary channels.

Method:
A small learnable fusion stem mapped 8 input channels to a 3-channel image, which was then used by YOLO-OBB.

29. Proposed Novel Method Direction

The main gap observed from experiments is:

Simple polarimetric image fusion does not outperform the single VV YOLO-OBB baseline. Therefore, a stronger method should perform detection-aware polarimetric fusion inside the model rather than generating a fixed fused image before detection.

Proposed method idea:

Detection-Aware Polarimetric Fusion YOLO-OBB

Core idea:

1. Use HH, HV, VH and VV complex inputs.
2. Represent each channel using magnitude, phase or real/imaginary components.
3. Use separate shallow branches for co-pol and cross-pol information.
4. Apply channel attention and spatial attention to learn which polarization channels help each component.
5. Fuse features inside the detector backbone.
6. Train the full model using oriented detection loss.

Expected contribution:

Instead of using fixed Pauli fusion or image-level learned fusion, the proposed method lets the detector learn polarimetric importance directly for component localization and classification.
