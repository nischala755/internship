1. OBJECT DETECTION ON POL-ISARSpaceTarget-1.0
============================================================

Dataset status:
- The previous dataset contains object/component annotations.
- Annotation format includes rotated bounding boxes.
- Example annotation type: robndbox.
- DOTA-style labelTxt files are also available:
  x1 y1 x2 y2 x3 y3 x4 y4 class difficult

Therefore, this is not only a classification dataset. It can be used for oriented object detection of satellite components.

Detected component classes include examples such as:
- parabolic_antenna
- solar_array
- plate_fitting
- polygon_body
- rod_fitting

Proposed detection baseline:
- YOLO-OBB on single-polarization VV amplitude images.

Proposed novel method:
- Polarimetric Pauli-Fusion YOLO-OBB.
- Construct a 3-channel image from full-pol complex channels:
  R = |HH - VV|
  G = |HV + VH|
  B = |HH + VV|
- Train an oriented object detector on this fused polarimetric representation.
- Compare with the single-pol baseline.

Why this can be presented as a novelty:
- Standard object detection models usually treat the radar image as a normal image.
- The proposed method injects radar polarimetric scattering information into the detector input.
- Oriented bounding boxes are better suited than axis-aligned boxes for ISAR satellite components.
- This gives both detection and polarimetric interpretation value.

Experiments to run:
1. Single-pol VV YOLO-OBB baseline.
2. Pauli-fusion YOLO-OBB proposed method.
3. Optional: HH/HV/VH/VV separate single-pol ablation.
4. Optional: Pauli-fusion + small attention block if we later move beyond Ultralytics.
5. Optional: compare YOLO-OBB with transformer-based detection, if time permits.

Metrics:
- mAP50
- mAP50-95
- precision
- recall
- per-class AP
- confusion matrix if available
- inference time

Output notebook:
- POLISAR_OBB_Detection_PauliFusion_YOLO.ipynb

Translation workflow:
1. Extract PDF text page by page.
2. Translate each section into English.
3. Preserve equations, figures, tables, and technical terms.
4. Prepare a section-wise summary.
5. Prepare a gap table:
   - What the authors did.
   - What they did not do.
   - How our work extends it.

Expected gap directions:
- If the paper mainly focuses on dataset construction and imaging:
  Gap: limited deep-learning benchmark on detection/classification.
- If the paper only performs classification:
  Gap: component-level oriented detection is not explored.
- If the paper uses only amplitude:
  Gap: phase and polarimetric fusion are underused.
- If the paper does not test cross-dataset generalization:
  Gap: transfer/generalization between Pol-ISARSpaceTarget and TFPSSTD remains open.
- If the paper does not use modern OBB detectors:
  Gap: no oriented object detection benchmark on polarimetric ISAR.
